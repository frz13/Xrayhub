# XrayHub

XrayHub — клиент для Windows, который управляет подключениями через **Xray Core**. В приложении можно хранить серверные профили, подключаться в режиме прокси или TUN, задавать DNS и настраивать правила маршрутизации.

## Возможности

- Импорт профилей по ссылкам `vless://`, `vmess://`, `trojan://` и `ss://`.
- Импорт Xray JSON-конфигураций и HTTPS-подписок, в том числе подписок в Base64.
- Обновление подписок вручную или автоматически по заданному интервалу.
- Проверка отклика серверов.
- Два режима подключения: **Прокси** и **Туннель (TUN)**.
- Локальные SOCKS5- и HTTP-входы. По умолчанию используются порты `10808` и `10809`; порты можно изменить в настройках.
- Возможность включить системный прокси Windows в режиме «Прокси» и задать авторизацию локального SOCKS5.
- Настройка DNS, MTU и параметров Xray Core, включая Mux и фрагментацию.
- Тёмная и светлая темы, русский и английский интерфейс, работа через системный трей и журнал событий.

## Режимы подключения

### Прокси

XrayHub запускает локальные SOCKS5- и HTTP-входы. При включённой настройке системного прокси приложение также направляет трафик программ, использующих прокси Windows, через локальное подключение.

### Туннель (TUN)

Xray Core создаёт виртуальный сетевой интерфейс и обрабатывает проходящий через него трафик. В этом режиме доступны настройки DNS, MTU, обхода частных сетей, защиты от DNS-утечек и блокировки QUIC (UDP/443).

Для работы TUN требуются права администратора. Приложение запрашивает их при запуске.

## Маршрутизация

Пользовательские правила маршрутизации доступны в режиме **Туннель (TUN)**.

Можно выбрать маршрут по умолчанию и задать действия для отдельных доменов или приложений:

- **Прокси** — отправлять трафик через выбранный сервер.
- **Напрямую** — использовать прямое подключение.
- **Блокировать** — не пропускать соответствующий трафик.

Для приложений правило задаётся по исполняемому файлу (`.exe`). Правила приложений имеют приоритет над правилами доменов. Изменения правил сохраняются автоматически и применяются при следующем подключении.

## Установка и запуск

1. Скачайте ZIP-артефакт **XrayHub-Windows-x64** из успешного запуска workflow в разделе **Actions** репозитория.
2. Распакуйте архив целиком в отдельную папку.
3. Запустите `XrayHub.exe`.
4. Добавьте ссылку на сервер, HTTPS-подписку или файл конфигурации, выберите профиль и режим подключения.

**Не переносите один `XrayHub.exe` отдельно от папки `core`.** Ядро должно находиться по пути `core\xray.exe` рядом с приложением:

```text
XrayHub/
├── XrayHub.exe
└── core/
    └── xray.exe
```

В готовой сборке .NET Runtime включён в приложение — отдельно устанавливать его для запуска не требуется.

## Сборка из исходников

Для локальной сборки на Windows нужен **.NET 10 SDK**. Перед сборкой положите файлы Xray Core в папку `core` проекта, чтобы в ней находился `core\xray.exe`, затем запустите `build.bat`.

Также проект содержит GitHub Actions workflow `.github/workflows/build-windows.yml`. Он запускается при push в ветку `main` или вручную через **Actions → Build XrayHub (Windows x64) → Run workflow**. Workflow собирает self-contained x64-публикацию, скачивает закреплённую версию Xray Core, проверяет архив по SHA-256 и добавляет ядро в готовый ZIP-артефакт.

## Где хранятся данные

Профили, настройки и рабочие файлы хранятся отдельно от папки приложения, в `%APPDATA%\XrayHub`:

```text
%APPDATA%\XrayHub/
├── profiles.json
├── settings.json
├── proxy-conflict-state.json
└── runtime/
    └── config.json
```

Поэтому обновление файлов приложения обычно не требует удаления пользовательских профилей и настроек.

## Ограничения текущей версии

- В качестве сетевого движка используется Xray Core. Ядра Sing-box и Mihomo не входят в проект.
- TUN использует встроенный стек **gVisor**. Переключение на System или Mixed в этой версии не предусмотрено.
- Пользовательские правила маршрутизации доменов и приложений работают только в режиме TUN.
- Импорт Shadowsocks-ссылок с параметром SIP002 `plugin` не поддерживается.

Поддержка конкретного профиля также зависит от его параметров и совместимости с используемой версией Xray Core.
